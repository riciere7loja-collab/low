Tutorial de integração

1 · Meta Pixel (obrigatório p/ anúncios)
  1. Abra o Gerenciador de Eventos da Meta (business.facebook.com/events_manager2).
  2. Selecione o pixel da sua conta de anúncios (ou crie um em Conectar dados → Web).
  3. Copie o ID do conjunto de dados (número de 15-16 dígitos no topo).
  4. Cole no campo ao lado e salve. Pronto: a loja passa a disparar PageView, InitiateCheckout, AddPaymentInfo e Purchase.
2 · Token da CAPI (recomendado)
  1. No mesmo pixel, abra Configurações.
  2. Desça até API de conversões → Gerar token de acesso.
  3. Copie o token (começa com EAA…) e cole aqui.
  4. Com ele, toda venda confirmada pelo webhook vira um Purchase server-side — com deduplicação automática contra o evento do navegador.
3 · Como conferir se está tudo certo
  1. Use o botão Testar integração ao lado.
  2. Instale a extensão Meta Pixel Helper no Chrome e abra a loja: o pixel deve aparecer verde com PageView.
  3. Na aba Testar eventos do Gerenciador, abra a loja com o código de teste e veja os eventos chegando ao vivo.
4 · Webhook ProPix (recuperar 100% das vendas)
  1. No painel da ProPix (app.propixbr.com), vá em Configurações ou Webhooks.
  2. Cole a URL de Notificação informada acima: .../api/webhook/propix.
  3. Pronto! Quando o cliente pagar no app do banco e fechar o navegador, a ProPix avisa o site e a venda é confirmada na hora no seu painel.
